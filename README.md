# mini-food-waste-app
A simple Python console application to reduce food waste by allowing restaurants to add leftover food and users to claim it.
# 🍽️ Mini Food Waste Reduction App

## 📌 Project Overview

The **Mini Food Waste Reduction App** is a simple Python console application designed to help reduce food waste.
Restaurants can add leftover food, and users can view and claim the available food.

This project demonstrates the use of **basic Python programming concepts** such as lists, dictionaries, functions, loops, and conditional statements.

---

## 🚀 Features

* Add leftover food from restaurants
* View available food items
* Claim food easily
* Simple menu-driven interface
* Prevents food waste by connecting restaurants and users

---

## 🛠️ Technologies Used

* Python
* Lists
* Dictionaries
* Functions
* Loops and Conditional Statements
